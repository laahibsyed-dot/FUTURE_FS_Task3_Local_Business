# Spice Route Kitchen — FUTURE_FS Task 3

A professional responsive website concept for a real local-business style restaurant, built with **HTML, CSS and JavaScript**.

## Task
**Future Interns — Full Stack Web Development Task 3**

Build a professional website for a real local business and pitch it to the owner as a live project.

## Business
**Spice Route Kitchen**  
A local Indian restaurant concept based in Gudur, Andhra Pradesh.

> Replace the demo business name, address, phone number, menu and other details with the actual local business details before pitching it to an owner.

## Features
- Responsive mobile, tablet and desktop design
- Restaurant hero section with clear call-to-action
- About / story section
- Customer-favourite menu
- Weekend special offer
- Customer testimonials
- Table reservation form with JavaScript interaction
- Automatic minimum reservation date
- Contact and location section
- Accessible form labels and status message
- No framework required
- GitHub Pages / Netlify compatible

## Run locally
1. Download/extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use VS Code Live Server.
4. Test the navigation and reservation form.

## Deploy on GitHub Pages
1. Create a public repository, for example `FUTURE_FS_03`.
2. Upload all files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and open the generated GitHub Pages URL.

## Deploy on Netlify
Drag and drop the extracted project folder into Netlify's deployment area, or connect the GitHub repository.
